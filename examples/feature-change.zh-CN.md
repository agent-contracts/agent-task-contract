# 功能开发：持续明确改动范围

## 场景

在已有订单页面增加 CSV 导出。这个任务不应该演变成表格组件重写，也不需要新增完整报表系统。

## 提示词

```text
Use $agent-task-contract to add CSV export to the orders page.
```

## 任务契约

```markdown
目标：
- 增加导出按钮，将当前可见订单数据下载为 CSV。

非目标：
- 不替换表格组件。
- 不增加定时报表。
- 不修改后端分页行为。

风险：
- CSV 中的逗号和引号必须正确转义。
- 页面筛选条件仍然需要控制导出数据。

完成标准：
- 页面展示导出按钮。
- 下载的 CSV 与筛选后的数据一致。
- CSV 转义测试通过。

验证计划：
- 运行 CSV 工具测试。
- 构建前端。
- 在浏览器检查订单页面。
```

## 交付说明

```markdown
## Summary
- 为筛选后的订单表格增加 CSV 导出。
- 正确转义导出内容中的逗号和引号。

## Verification
- `npm test -- csv.test.ts`
- `npm run build`
- 浏览器检查：导出按钮可以下载筛选后的数据。

## Risks / Notes
- 超大数据集仍受页面现有客户端数据量限制。
```
