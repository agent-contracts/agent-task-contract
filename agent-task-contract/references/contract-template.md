# Task Contract Template

Use this template for large, ambiguous, risky, or multi-turn tasks. Keep it short; the contract is a working control surface, not a project document.

```markdown
## Task Contract

Objective:
- ...

Non-goals:
- ...

Known constraints:
- ...

Relevant context to inspect:
- ...

Assumptions:
- ...

Risks:
- ...

Completion criteria:
- ...

Verification plan:
- ...

Evidence captured:
- ...
```

## Update Rules

- Update the contract when the discovered repo behavior contradicts the initial assumption.
- Add a non-goal when the task starts pulling in tempting but unrelated work.
- Replace vague criteria such as "works" with observable criteria such as "the checkout form rejects invalid ZIP codes and the targeted test passes."
- Keep user-facing commitments separate from internal guesses.
